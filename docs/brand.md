# AMUN visual identity

AMUN's emblem is an original, decorative interpretation of the ancient Egyptian god
Amun. The double-plume crown identifies the subject, while the surrounding ring echoes
AMUN's observer-only monitoring and permanent achievement record. It is not a copy of
a specific artifact, a historical reconstruction, or an affiliation with a museum,
religious institution, Egypt, Nintendo, or Luma3DS.

## Marks

| Asset | Intended use |
|---|---|
| `assets/branding/amun-mark.png` | 1254 px transparent master for documentation and release presentation |
| `studio/assets/amun-mark-256.png` | Studio window/taskbar icon |
| `studio/assets/amun-mark-64.png` | Studio application header |

Use the emblem with generous clear space and do not stretch, skew, crop, recolor, or
place it on a visually noisy background. At very small sizes, prefer the supplied
64 px derivative rather than resampling the master at runtime. The mark contains no
wording; pair it with the product names `AMUN 3DS` or `AMUN Studio` in normal UI text.

## Palette

| Name | Value | Role |
|---|---|---|
| Midnight | `#071A36` | Studio identity bar and dark fields |
| Deep lapis | `#0A2F78` | Primary emblem color |
| Antique gold | `#E6B84B` | Identity accent and title |
| Papyrus | `#F3E8CB` | Light text and restrained highlights |
| Obsidian | `#090B0D` | Silhouette and high-contrast detail |

AMUN's written voice remains technical, calm, and explicit about evidence. Egyptian
motifs are flavor, not terminology for security states, failures, game identities, or
hardware claims. Avoid fake hieroglyphs, faux translations, sacred claims, and imagery
that could be mistaken for an official platform or cultural institution.

The master artwork was generated specifically for this repository with OpenAI's
built-in image-generation tool, then mechanically resized with alpha preserved for
the Studio variants. It is distributed with the project under the repository license
to the extent legally permitted.
